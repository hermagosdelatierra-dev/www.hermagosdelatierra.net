Proyecto AUNA

Hermagos de la Tierra es en realidad un proyecto que forma parte de otro proyecto mayor, el Proyecto AUNA, que también está en fase de materialización hace unos meses.

AUNA es un proyecto de HOLOTOPÍA y Comando Creativo. Es una plataforma colaborativa pensada como herramienta para el desarrollo de proyectos holísticos.

Equipo promotor del proyecto AUNA:

  • Juan de Dios López-Rienda (Comando Creativo)
  • Eva Deumal (Destino Gaia)
  • …

[Hermag@os de la Tierra] forma parte de este proyecto, el prototipo que estamos creando es el primero ejemplo funcional del tipo de redes colaborativas que se podran crear con AUNA.

AUNA permite crear redes/comunidades que pueden ser articuladas en torno a un tema o ámbito geográfico concretos, construyendo comunidades que se autogobiernan y desarrollando modelos de sostenibilidad replicables en otros ámbitos temáticos o territoriales.
Objetivos: distribución de la riqueza, autogobierno, desarrollo sostenible, modelos holísticos.

Aúna es posible gracias a la colaboración e integración de varias tecnologías:

Implementación del modelo de autogobernanza, criptomonedas, blockchain

El propósito de Hypha es construir e implementar soluciones y servicios tecnológicos colaborativos para coordinar el prosperidad humana y el bienestar planetario en armonía con la naturaleza.
La palabra «Hypha» se refiere a la Internet terrestre original. Imitamos sistemas naturales en nuestras herramientas DAO para coordinar y respaldar ecosistemas organizacionales prósperos.

Software de desarrollo de la plataforma

Genio de Quidgest es una plataforma ágil para el modelado y generación automática de sistemas de información integrados, en diferentes arquitecturas y lenguajes. Basada en metodologías como MDD (Model Driven Devlopment), RAD (Rapid Application Development) y DevOps, se recomienda especialmente para proyectos complejos, únicos y urgentes.

Sistema de productividad. Gestión eficiente de equipos y proyectos

ClickUp es una aplicación que los sustituye a todos. ClickUp funciona para todo tipo de equipos, por lo que todos ellos pueden utilizar la misma aplicación para planificar, organizar y colaborar. La misión principal de ClickUp es hacer que el mundo sea más productivo eliminando la fricción causada por el uso de tantas aplicaciones diferentes.
